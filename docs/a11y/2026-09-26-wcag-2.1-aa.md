## Result

The published site does not pass WCAG 2.1 Level AA. Two contrast failures are open on pages a visitor can reach.

`pnpm a11y:web` (`apps/web/scripts/a11y-check.mjs`) would still print a pass. On the same ten routes and both consent states, axe reported **0 violations** at 1280×900. That script only records `violations`, so it drops axe `incomplete` results, and it never resizes. Both open failures sit in that gap.

## Open failures — published pages

### 1. 1.4.3 Contrast — primary buttons inside `.prose`

Serious. Ratio **1:1**. Text and fill are both `#c9a77a`.

| Page | Control |
| --- | --- |
| `/how-it-works` | “Get started” (`a.btn.btn-primary`) |
| `/404` | “Back to Anchor” (`a.btn.btn-primary`) |

Axe files these as `color-contrast` **incomplete** (“Element has a 1:1 contrast ratio with the background”), on both consent states and at 320px. A computed-style check measures the same 1:1.

Cause: `.prose a` sets `color: var(--brand)` and outranks `.btn-primary` (`#1a1a1a` on `#c9a77a`, which is about 7.7:1).

```298:301:apps/web/src/styles/tokens.css
.prose a {
  color: var(--brand);
  font-weight: 600;
}
```

```226:231:apps/web/src/styles/tokens.css
.btn-primary,
.slate-btn-primary {
  background: var(--brand);
  color: #1a1a1a;
  border-color: var(--brand);
}
```

Markup: `apps/web/src/pages/how-it-works.astro` (the “Get started” link) and `apps/web/src/pages/404.astro` (the “Back to Anchor” link).

Later fix: keep `.prose a.btn` (or at least `.prose a.btn-primary`) on the button text color, `#1a1a1a`. The secondary buttons in those same rows already pass; `.prose a` paints them `#c9a77a` on the dark page background.

### 2. 1.4.3 Contrast — demo chat switch below 52rem

Serious. At 320×640, axe reports a **violation** on `/app`:

- Control: the selected tab “Family group” (`.mvp-switch button[aria-selected="true"]`)
- Colors: `#f4fffc` on `#c9a77a`
- Ratio: **2.21:1** (needs 4.5:1; 15.2px bold is not large text)

```284:288:apps/web/src/components/MvpDemo.css
.mvp-switch button[aria-selected='true'] {
  background: var(--brand);
  color: #f4fffc;
  border-color: var(--brand);
}
```

The switch is `display: none` until `max-width: 52rem`, so a 1280px run never sees it. At desktop width `/app` had 0 violations.

Later fix: use the same dark label as `.btn-primary` (`color: #1a1a1a`). That pairing is about 7.7:1.

## Design studies

`/designs/*` is not in the sitemap or the primary nav. Linen, mist, and quiet had no axe violations. Quiet’s background is a gradient, so axe left contrast **incomplete**; the declared ink (`#1a1917`, `#4a4742`) on the paper stops (`#f7f4ed`–`#e8e4db`) is about 8.4:1 to 16:1.

### `/designs/slate` — 1.4.3 and 1.4.10

The page loads `slate.css` and not `tokens.css`. `.slate` sets light text and does not set a page background, so the canvas stays white.

| Element | Ratio | Needs |
| --- | --- | --- |
| `h1.slate-brand` “Anchor” — `#f2f0eb` on `#ffffff` | 1.13 | 3:1 (large) |
| `.slate-line` | 1.13 | 3:1 (large) |
| `.slate-support` — `#c4bfb5` on `#ffffff` | 1.83 | 4.5:1 |
| `.slate-btn-ghost` “How it works” | 1.13 | 4.5:1 |
| `.slate-link` “Get started” — `#c9a77a` on `#ffffff` | 2.26 | 4.5:1 |
| Skip link (unstyled; `.slate-skip` lives in `tokens.css`) — default link blue | 2.23 | 4.5:1 |

At 320px the document scrolls horizontally by 54px (`scrollWidth` 374, `clientWidth` 320). Offenders include `main.slate-main`, `.slate-hero`, and `.slate-actions`. That is 1.4.10 Reflow. The homepage uses the same slate classes inside `BaseLayout`, which loads `tokens.css`, and it passed both contrast and reflow.

Later fix: give this page the same dark canvas as the live site (import `tokens.css`, or set `background` on `.slate`), and stop the action row from growing past the viewport.

### `/designs/ink` — 1.4.3

Index labels “01”, “02”, “03” (`.ink-action-index`) are `#787878` on `#ffffff`, **4.41:1**, just under 4.5:1. They are `aria-hidden` and still visible. Cause is `opacity: 0.55` in `apps/web/src/components/designs/ink/ink.css`. Same result at 320px, and that page does not overflow.

Later fix: a solid color at 4.5:1 or higher, instead of opacity on black.
