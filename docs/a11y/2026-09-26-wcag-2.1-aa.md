## Fix later

### 1. Primary buttons inside `.prose` — WCAG 1.4.3

`.prose a` in `apps/web/src/styles/tokens.css` is more specific than `.btn-primary`, so anchor buttons inside `<article class="prose">` get primary-colored text on a primary background. axe reports this as incomplete (“1:1 contrast ratio”), which is why the gate stays green.

### 2. High contrast widget — WCAG 1.4.3

`html.a11y-contrast` in `tokens.css` sets the page background to the text color (`#050315`) and paints links and primary buttons with `--primary` (`#433BFF`). axe measured that pair at about 3.25:1. Normal text needs 4.5:1. The class is applied from `anchor-a11y-prefs-v1` before paint, with the accessibility panel closed.
