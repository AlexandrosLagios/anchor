1 · Before the demo

2 · The call gate for beat 6

Caution: set ANCHOR_BOT_ONLY=true before the service opens. Without it, a public anchor-bot serves the website API and the WhatsApp webhook, and the webhook sends the Twilio key to any media URL. The commands are in "Phone calls" in DEPLOY.md, and each step needs the user's go.

pnpm deploy:bot keeps the binding, the variables, and the timeout. A full gcloud run deploy with the flags of "Deploy" closes the service again. To close the service on purpose, remove the allUsers binding.

3 · Reset and prepare

4 · Rules that keep the live bot healthy

One poller per token. The dev bot runs locally with pnpm dev:api, from a worktree whose apps/api/.env.local holds the dev bot token, OPENAI_API_KEY, and TZ=Europe/Athens. Only one process may poll one token.

5 · Rehearse twice

/fastforward moves the clock of the whole bot for good. The rehearsals run on the dev bot @anchor_family_dev_bot, in its own group. On the live bot, the only jump is beat 6 on stage.

6 · Deploy a fix

From a clean checkout of origin/main, after the fix PR merges. The script tests, builds, pushes, and rolls out.

git switch --detach origin/main
pnpm deploy:bot

A few 409 lines in the first seconds are the old revision shutting down.

8 · If the bot behaves oddly

SymptomLikely causeAction
No ❤ on a photoThe model is slow, or the bot is downWait 15 s. Then check the logs.
No reply to anythingNo family in the record: the bot never saw itself joinRemove Anchor from the group, add it again, promote it.
409 lines keep comingA second process polls the same tokenStop every local run that uses that token.
No ring in beat 6No phone or "Call me" off for Sofia, a missing TWILIO_FROM or ANCHOR_PUBLIC_URL, the Twilio geo permissions, or no allUsers bindingWalk the call gate checklist, then check the logs.
The call rings, but Anchor stays silentThe Realtime session failed before the opener, or Twilio cannot reach wss:// on ANCHOR_PUBLIC_URLAnchor hangs up on a Realtime error. Check the logs for "Refused a call stream".
