3 · Rules that keep the live bot healthy

One poller per token. Never run the bot locally with the @anchor_family_bot token. Local runs use the dev bot @anchor_family_dev_bot, whose token is in apps/api/.env.local.
No /fastforward on the live bot before the demo. It moves every family's clock for good, and dates in the gentle help shift with it.
/private must be a reply to the person's message. From the "/" menu it gets a how-to line.

4 · Deploy a fix

From a clean checkout of origin/main, after the fix PR merges. The script tests, builds, pushes, and rolls out.

git switch --detach origin/main
pnpm deploy:bot

A few 409 lines in the first seconds are the old revision shutting down.
